GYRO DODGE 3D — 完成版（日本語・英語対応 / 9種3D障害物 / ボタン非重複・300x250広告対応）

【主な仕様】
1. デザイン＆UI（style.css / index.html）
   - 全ボタンからグラデーション・AI風装飾を排除し、ソリッド＆マットな航空計器デザインに統一
   - 日本語 / 英語（JP / EN）ワンタップ切替対応
   - 外部オーバーレイ広告による下部ボタン隠れを自動検知して余白を確保し、フライト中は広告を完全非表示化

2. ゲームバランス＆3D造形（models3d.js / game.js）
   - 難易度別の目標・平均到達距離：かんたん 25,000m / ふつう 15,000m / むずかしい 8,000m / げきむず 5,000m
   - 放置・同じ位置・画面端（四隅）への居座りに対して直撃弾を配置しつつ、必ず通過可能な安全回廊を数学的に保証
   - 9種類の3D障害物（機雷・回転レーザー梁・十字タービン・鉄骨ピラー・可動シャッター・結晶スパイク・電磁コイル環・岩塊・追尾ドローン）
   - リング通過で +500〜+2,500点のコンボボーナス加算（高速時のすり抜け防止Swept-Z判定対応）
   - 1,000 km/h超でもステージや空が消えない無限ループ補正済み

3. 広告配置（復活広告なし）
   - 300×250枠（87fa901da9b109d36175d5520669b54a）：リザルト画面専用300×250枠（ボタンより下に分離）、ステージ選択下部、通信対戦ロビー下部、PC右余白
   - 320×50枠（232ea9edd775ef7eee19594e2da5102b / 6deabf2adba66b7bba510d1b374de414）：ホーム最下部、格納庫下部、設定下部、リザルト最下部、PC左余白
