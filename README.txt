# GYRO DODGE 3D（フルボイス＆最大10人協力・バトル版）

## 遊び方
1. **index.html** をダブルクリックしてブラウザ（Chrome / Safari / Edge など）で開きます。
2. お手元の録音音声（全7ボイス）はすでにゲーム本体に内蔵されているため、**ファイル読み込み不要ですぐにあなたの声で再生されます**。
3. サーバーに公開（GitHub Pages / Netlify / Vercel など）すると、PCモニターのQRコードをスマホで読み取って**最大10人同時プレイ（協力＆お邪魔バトル）**が楽しめます。

## 同梱ファイル一覧
- `index.html` : ゲーム本体（全7ボイス内蔵済み・1ファイルで完結）
- `logo.svg` : アプリロゴ（アイコン画像）
- `voices/` : 収録いただいた7種類の音声ファイル一式
  - `01_yahho.mp3`（ヤッホー）
  - `02_start.mp3`（準備はできた？よーい。スタート！）
  - `03_abuna.mp3`（あぶなっ！）
  - `04_good.mp3`（いいよ！その調子！）
  - `05_speedup.mp3`（スピードアップ！）
  - `06_clear.mp3`（クリア！おめでとう！）
  - `07_gameover.mp3`（残念、ゲーム失敗）
